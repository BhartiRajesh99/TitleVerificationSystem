# 🏷️ Title Verification System

## 📌 Project Overview

The **Title Verification System** is a smart, AI-powered web application designed to **verify land/property titles digitally** by analyzing ownership details, document metadata, and textual similarities.  
It helps eliminate **fraud, duplication, and manual verification delays** by automating the verification process using **Natural Language Processing (NLP)** and **fuzzy matching techniques**.

This system is especially useful for:
- Government land record departments
- Scholarship & property verification systems
- Legal document verification
- Digital governance platforms

---

## 🎯 Problem Statement

Traditional title verification is:
- Manual and time-consuming  
- Prone to human errors  
- Vulnerable to fraud and document tampering  
- Inefficient for large-scale datasets  

There is a strong need for a **paperless, automated, and intelligent verification mechanism**.

---

## 💡 Solution

The Title Verification System provides:
- Digital submission of title data
- AI-based text normalization and comparison
- Similarity scoring for verification probability
- Secure authentication using cookies/JWT
- A clean, responsive UI for users and administrators

---

## ⚙️ Features

### 🔐 Authentication & Security
- Secure login using **JWT + HTTP-only cookies**
- Role-based access (Admin / User)
- Protected API routes

### 📄 Title Verification
- Upload or submit title details
- Normalize title text (case, spacing, symbols)
- Apply **Soundex & Metaphone** phonetic matching
- Calculate similarity using **Fuzzy Matching**
- Generate a **Verification Probability Score**

### 📊 Admin Dashboard
- View all verification requests
- Filter by status, state, and verification score
- Approve or reject titles
- Analytics & statistics

### 🧠 AI & NLP Capabilities
- Text preprocessing
- Fuzzy string comparison
- Phonetic algorithms
- Confidence-based verification logic
- Give suggestions for rejection titles

### 🎨 User Interface
- Responsive and modern UI
- Debounced search & filters
- Beautiful error & 404 pages
- Clean UX using React
